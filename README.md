# umwug-aa-to-gas-examples

This repository contains example projects used at the University of Minnesota Libraries to connect Alma Analytics data to Google Apps Script. Each folder contains scripts pertaining to a separate project. The scripts here have been slightly modified and redacted from their production versions.

This was created for a presentation at the 2026 Upper Midwest User Group (UMWUG) Conference. UMWUG is a regional user group of Ex Libris Users of North America (ELUNA).

## Configuration

Each project has its own separate `README.md` file within its folder, describing the configuration process. In addition to the configuration steps listed, one will likely want to change things about the script for their own purposes and local setups; these are *not* intended to be able to be used exactly as-is.
